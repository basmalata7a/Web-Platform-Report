مشروع في تصميم صفحات الويب

تصميم صفحات الويب باستخدام CSS

يتناول هذا المشروع دور CSS في تنسيق صفحات الويب، مع تطبيق عملي يوضح تأثير الألوان والخطوط والمسافات والتصميم المتجاوب على شكل الصفحة.

مقدمة عن الموضوع

.web-page {

  color: #2563eb;

  font-size: 18px;

  padding: 20px;

  background-color: white;

}

مثال على تنسيق عنصر

يتغير شكل العنصر عند تعديل خصائص CSS.

مقدمة

ما المقصود بتصميم صفحات الويب؟

يعتمد تصميم صفحات الويب على تنظيم المحتوى وتحديد طريقة عرضه للمستخدم. وتُستخدم HTML لبناء هيكل الصفحة، بينما تُستخدم CSS لتنسيق العناصر والتحكم في مظهرها.

01

HTML

تُستخدم HTML لتحديد عناصر الصفحة، مثل العناوين والفقرات والصور والروابط.

02

CSS

تُستخدم CSS لتحديد الألوان والخطوط والخلفيات والمسافات وطريقة ترتيب العناصر.

03

التصميم المتجاوب

يساعد التصميم المتجاوب على تكييف تخطيط الصفحة مع عرض الشاشة المستخدمة.

المفاهيم الأساسية

أهم خصائص CSS المستخدمة في التصميم

يمكن التحكم في مظهر عناصر الصفحة من خلال مجموعة من الخصائص التي تحدد طريقة عرض المحتوى.

الألوان والخلفيات

تحدد خصائص مثل color وbackground-color لون النص والخلفية.

الخطوط والنصوص

تتحكم خصائص مثل font-size وfont-family في حجم الخط ونوعه.

المسافات والتخطيط

تساعد خصائص مثل margin وpadding وdisplay في تنظيم العناصر وتحديد المسافات بينها.

التطبيق العملي

اختبار تأثير خصائص CSS

في هذا المشروع، أنشأنا صفحة ويب باستخدام HTML وCSS، وجرّبنا تغيير الألوان وأحجام الخطوط والمسافات لمعرفة تأثيرها على شكل الصفحة. كما اختبرنا تصميم الصفحة على أحجام مختلفة من الشاشات للتأكد من أن العناصر تظهر بصورة مناسبة على الكمبيوتر والموبايل. يوضح التطبيق كيف يمكن استخدام CSS للتحكم في مظهر صفحات الويب وتنظيم عناصرها.
